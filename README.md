# 简程

以「今天」为中心的桌面日程：一只大钟、一条从白天到夜晚的色带，有时间的日程贴在色带上，没定时间的待办在色带里失重漂浮。按电脑上的应用使用情况**自动勾选**重复性任务。

黑白、只有浅色。时间的明暗交给色带：白天近白，日落后渐渐变成浅灰。

## 安装与运行

- 普通用户：从 [GitHub 发布页](https://github.com/zonglingzhang0-a11y/jiancheng-releases/releases) 下载最新的 `Jiancheng-Setup-x.y.z.exe` 安装，可以选择安装位置。安装包没有代码签名，首次运行时 Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」。之后的新版本会自动更新。
- 开发：

```bash
npm install
npm run dev        # 开发模式（热更新），用测试版的数据文件夹
npm run web        # 仅在浏览器里预览界面（模拟数据，无监测功能）
npm run beta       # 打包测试版安装包，输出到 release/test/（不发布）
npm run dist       # 打包正式版安装包，输出到 release/（不发布，只能在 main 分支）
npm run release    # 打包并发布正式版到 GitHub（需要环境变量 GH_TOKEN）
npm run icons      # 重新生成应用与托盘图标
```

### 源码、测试版与正式版

| | 分支 | 版本号 | 数据文件夹 | 自动更新 |
| --- | --- | --- | --- | --- |
| 正式版 | `main`，每次发布打一个 `v版本号` 标记 | `1.0.0`、`1.1.0` | `%APPDATA%\Jiancheng` | 从 GitHub 拉正式版 |
| 测试版 | `dev`，日常开发都在这里 | `1.1.0-beta.1` 这样带预发布号 | `%APPDATA%\Jiancheng-Test` | 不检查 |

- 开发模式和带预发布号的版本都算测试版：标题栏标着「测试版」，用自己的数据文件夹和单实例锁，可以和正式版同时开着，不会碰到正式版里的真实日程。
- 测试版安装包叫「简程测试版」，和正式版装在不同位置、各有各的开始菜单项，可以同时装着。
- 发新的正式版：在 `dev` 上测好 → 把 `package.json` 的版本号改成正式版本（去掉 `-beta.x`）→ 合并到 `main` → 在 `main` 上 `npm run release`，成功后自动打上 `v版本号` 标记 → 回到 `dev`，把版本号改成下一个测试版。
- `npm run beta / dist / release` 打包前会先检查分支、版本号和有没有没提交的改动，不对就停下并说明原因。

版本号：上线前的测试版用过 0.x，1.0.0 起正式版之间的测试版一律带 `-beta.x`。从旧版本升级时，日程、完成记录和监测数据原样保留。

## 自动更新

- 安装包发布在只放安装包的公开仓库 [jiancheng-releases](https://github.com/zonglingzhang0-a11y/jiancheng-releases)，源码不公开。
- 程序启动 15 秒后检查一次，之后每 4 小时检查一次；有新版本在后台下载，下载完在标题栏显示「重启更新」，不重启的话下次退出时自动安装。
- 设置 → 系统 里能看到当前版本、手动检查更新。
- 发新版：改 `package.json` 里的版本号 → `npm run release`。访问令牌只放在本机的 `GH_TOKEN` 环境变量里，不写进代码，也不会打进安装包。

## 首页

- **日期**：月日、周几、农历、节气。
- **大钟**：六种钟面（圆润、软衬线、霓虹线、手写、翻页钟、数码管），点一下切换是否显示秒。旁边的圆环是当前日程还剩多久。
- **现在**：正在做什么、还剩多久；空闲时显示下一项还有多久开始、空档里还有几项随时可做。
- **目录**：按晨、昼、暮、夜、随时分组，展开能看到子待办。
- **色带**
  - 0–6 点压缩显示；日出日落前后约一小时柔和过渡。
  - 有时间的日程是灰色色块，进行中的那块会随时间被填满。
  - 空闲较长的时段标出「空 X 小时」，从「现在」到下一项画一条虚线。
  - 上方是太阳（夜里是月亮）的轨迹。
- **漂浮的待办**
  - 没定时间的待办按固定方向匀速漂，碰到边框、日程块、别的待办就弹开，不会乱动。
  - 可以拖动、扔出去；点一下可以完成、排进时间轴或编辑。
  - 完成后先停一下，再按完成的先后慢慢移到色带左下角排成一行，排满了往上叠一行；取消完成会重新漂起来，后面的依次补位。
  - 最近 7 天没做完的一次性待办会顺延到今天，标着「昨天」「3 天前」。
- **规划今天**：色带里出现几个虚线空位，把待办拖进去就排好时间。重复的待办只改这一天。
- **日期条**：前后两周，每天一段迷你色带和完成度小圈，点哪天首页就切到哪天。「周」「月」展开这一周或这个月。

## 一句话添加

首页顶部、快捷面板里都能用。

| 输入 | 识别结果 |
| --- | --- |
| `明天下午3点 开会` | 明天 15:00–16:00 |
| `周五 10:00-11:30 看牙医` | 本周五 10:00–11:30 |
| `晚上8点 健身 1个半小时` | 今天 20:00–21:30 |
| `每天 背单词 30分钟 @不背单词` | 每天重复，在「不背单词」里用满 30 分钟自动打勾 |
| `每周一三五 刷题 @LeetCode 40分钟` | 每周一、三、五，窗口标题含 LeetCode 累计 40 分钟自动打勾 |

输入 `@` 会弹出最近使用的应用；`@` 后面不是应用名时按窗口标题关键词处理。按 `Shift+Enter` 带着识别结果进入详细编辑。

## 编辑

点日程从右侧滑出编辑栏，可以展开成整页（左侧显示当天的时间线）。

- 图标：按标题自动选，也可以手动挑。
- 时间：随时或定时间；重复可选每天、工作日、每周指定日，重复日程可以单独删除某一次。
- 子待办：重复日程的子待办每天单独勾选。
- 备注。
- 智能完成：

| 规则 | 适用场景 | 示例 |
| --- | --- | --- |
| 应用时长 | 在某些应用中累计使用 N 分钟 | VS Code 90 分钟 → 「深度工作」完成 |
| 窗口标题 | 标题包含关键词的时间累计 N 分钟，可限定应用 | Chrome 中「LeetCode」20 分钟 → 「刷题」完成 |
| 文件更新 | 文件或文件夹中有文件被修改 | 日记文件夹有保存 → 「写日记」完成 |

统计范围可选「全天」或「仅计划时段」。超过设定时长没有键鼠操作的时间不计入；看网课等场景可对单条规则开启「无操作时继续计时」。手动取消一个已自动完成的任务后，当天不会再被自动勾选。

## 桌角卡片

长期挂在桌面一角，在托盘菜单或「设置 → 外观」里切换。鼠标移到卡片上，右上角会出现关闭按钮，点一下就收起；顶部中间的小点是拖动把手。

| 尺寸 | 内容 |
| --- | --- |
| 小卡 | 剩余时间环、正在做的事、下一项、一条细日线；点一下打开主窗口 |
| 中卡 | 以上内容，加一条小色带（待办缩成漂浮的小圆点）、完成和新建按钮 |
| 侧栏 | 占满屏幕高度：时钟、竖向时间轴（前 1 小时、后 7 小时）、随时待办漂浮区、一周完成度 |

- 层级：置顶，或贴在桌面（在其他窗口之下）。
- 鼠标移开时变淡，漂浮也停下。
- 全屏看视频、玩游戏、演示时自动隐藏。
- 卡片按分钟更新，不跳秒，不在眼角抢注意力。

## 外观（设置 → 外观）

左边调节，右边实时预览首页时钟和三张桌角卡片。

- 10 套字体搭配（圆润、书卷、小薇、黄油、快乐、仪表、楷意、墨韵、手札、霓虹），作用于桌角卡片的数字、标题、正文、时间四个位置。
- 按位置自定义：可以从随应用提供的字体、本机已安装的字体、导入的字体里选；缺字或没有中文字形时会提示。
- 导入字体：ttf、otf、woff、woff2，复制到数据文件夹里。
- 首页显示项：钟面、秒、空档与间隔、太阳轨迹、任务图标、倒计时环、完成后排到左下角、漂浮速度、色带夜间灰度。

## 快捷面板与快捷键

- 快捷面板：单击托盘图标或按全局快捷键（默认 `Ctrl+Alt+Space`，可在设置里修改）弹出，能一句话添加、看今天、勾选，点别处自动收起。
- 主窗口快捷键：

| 按键 | 作用 |
| --- | --- |
| `N` | 一句话添加 |
| `Ctrl+N` | 新建日程 |
| `H` | 回到今天 |
| `←` `→` | 前一天 / 后一天 |
| `W` / `M` | 展开周 / 月 |
| `A` | 智能监测 |
| `L` | 设置 → 外观 |
| `Ctrl+,` | 设置 |
| `Ctrl+Enter` | 保存日程 |

## 智能监测与本地截屏

- 「监测」页：当前前台应用、活动时间线、应用使用排行、各智能任务进度、按时段整理的活动记录。可以翻看以前的日子。
- 本地截屏（设置 → 本地截屏，默认关闭）
  - 每隔 1–30 分钟截取当前窗口或整个屏幕，挂在对应的时段下。
  - 自动跳过：空闲、锁屏、简程自身窗口、不截屏名单中的应用、无痕浏览窗口、与上一张几乎相同的画面。
  - 超过保留天数自动删除。

## 隐私

只记录前台应用的进程名与窗口标题；开启本地截屏后另存截图。不记录键盘内容、不联网，所有数据保存在 `%APPDATA%\Jiancheng\`：

- `data.json`：日程、完成记录和设置
- `activity/YYYY-MM-DD.json`：每日活动片段
- `apps.json`：应用名称缓存
- `screenshots/`：截图、缩略图与索引
- `fonts/`：导入的字体
- `logs/issues.log`：窗口崩溃等异常记录（反馈问题时可以附上）

## 技术栈

Electron + React + TypeScript（electron-vite 构建），Win32 API 通过 [koffi](https://koffi.dev) 调用（无需编译原生模块），字体来自 Fontsource 并随包离线提供。

```
src/
  shared/     类型定义、重复规则、时长统计、一句话识别（主进程和界面共用）
  main/       主窗口 / 快捷面板 / 桌角卡片 / 托盘、Win32 采样、活动记录、规则引擎、截屏、字体导入
  preload/    安全的 IPC 桥
  renderer/
    home/     首页：时钟、目录、色带（失重漂浮）、日期条
    editor/   编辑侧栏与智能完成规则
    widget/   桌角卡片（小卡 / 中卡 / 侧栏）
    pages/    智能监测页
    components/ 设置（含外观）、选择器等通用组件
    mini/     快捷面板与卡片窗口入口
    lib/      色带绘制、物理、农历节气、字体、图标
scripts/gen-icons.cjs  生成应用与托盘图标
```
